# 固定画布共享与未来规划

目标：作者完成一次画布编排，其他人通过固定模板替换少量文字和素材，制作自己的视频。作者负责分镜与效果，使用者负责提供内容。

**实施更新：已按在线平台优先实现首版代码，费用由每个用户自己的渠道承担。** 最新实现范围、启动步骤及待验收边界以 [在线模板平台说明](docs/template-platform.md) 为准。以下保留早期规划作为设计背景，其中“当前状态”描述的是实施前的本地版本。

本文是本分支的产品规划。下文明确区分已有代码、当前交接方式和尚未实现的能力；完整待验收清单见 [pending-test](docs/content/docs/progress/pending-test.mdx)。

## 当前做到哪里

| 能力 | 当前状态 |
| --- | --- |
| 画布项目导出、导入 | 已有代码，项目 ZIP 可包含节点引用的本地素材；交接前需在另一浏览器验证 |
| 发布为工作流模板 | 已有本地发布入口，识别文字占位符、选择可替换图片，保存模板版本 |
| 填写变量、同款复刻/相似创作 | 已有页面，实例化为独立画布并记录快照；仍需相关流程验收 |
| 视频任务、续查、下载与合成 | 已有本地 Agent 工作流，字幕、Logo 等具体边界见待验收清单 |
| 跨用户模板链接、云端素材、账号权限 | 尚未实现；当前模板库主要存于浏览器 localForage |
| 强制锁定参数、隐藏作者提示词 | 尚未实现服务端保障；本地用户拿到画布后可以编辑 |

当前“同款复刻”和“相似创作”会附加不同生成指令，并保存模式信息。它们不代表模型能保证画面逐帧相同，也不代表已经实现完整的参数权限控制。

## 现在怎样让别人用我的画布

适合先交给少量熟悉工具的人，验证模板是否容易复用。

1. 在独立副本中整理一个模板画布，保留必要的分镜、配置和可分享参考素材。移除生成的视频节点、私人截图、任务记录及无关素材，避免改动原始创作项目。
2. 将可变文字写成 `{{brand_name}}`、`{{product_name}}` 等占位符。当前解析器要求变量名以英文字母开头，后接字母、数字、下划线或连字符。把可替换图片节点命名清楚。
3. 从画布项目入口导出项目 ZIP。检查包内 `projects.json` 和 `projects/.../files/`：只保留准备交付的内容，检查节点中是否残留密钥、私人路径或临时素材 URL。当前导出没有专门的脱敏和“只导出模板”保证。
4. 对方运行本分支，在画布项目页导入 ZIP，检查图片、连线、文字和配置是否完整。没有打包进去的远程 URL 或本机文件引用可能无法在对方环境读取。
5. 对方在导入的画布中使用“发布为工作流模板”，选择图片变量，再从本地模板库填写内容并创建自己的实例。当前画布导出不等于导出模板库的版本记录。
6. 对方配置自己的生成渠道；使用本分支完整 Seedance 流程时，运行本仓库版本的 [Canvas Agent](canvas-agent/README.md)，由 Agent 读取 `ARK_API_KEY` 或 `ARK_API_KEY_FILE`。不要把作者的密钥装进共享包，也不要假设上游 npm 包已包含本分支改动。
7. 先完成一次单独验收：素材可读取、变量替换正确、任务可查询、结果可下载。真实生成会产生渠道费用，开始前确认调用次数与计费方。

`.gitignore` 只影响 Git 收录，不控制浏览器导出的 ZIP。仓库已忽略视频文件和本地生成目录，但导出画布仍可能包含视频或敏感节点内容。Git 链接、画布包和未来的模板链接是三种不同的交付物。

## 固定哪些内容，开放哪些内容

建议第一版只提供“同款复刻”；相似创作在字段权限清楚后再对使用者开放。

| 项目 | 同款复刻 | 相似创作的后续目标 |
| --- | --- | --- |
| 分镜顺序、镜头数量、故事结构 | 固定 | 保留总体结构，仅开放指定镜头 |
| 模型、时长、比例、分辨率 | 作者固定 | 作者明确开放的选项才可更改 |
| 提示词主体、运镜、首尾帧关系 | 固定 | 允许改写明确标记的局部字段 |
| 品牌名、产品描述、人物或产品图片 | 按变量表替换 | 按变量表替换 |
| 字幕样式、Logo 位置、合成规则 | 作者固定，可暴露指定素材槽 | 只开放模板声明的选项 |

比如“酒店介绍”模板，作者固定镜头顺序和节奏，使用者上传酒店外观、客房照片和 Logo，填写酒店名与介绍文字。真实界面、中文、价格和经营指标由真实素材后期合成；生成模型负责适合的氛围镜头。

前端灰掉按钮只能减少误操作。若要求使用者无法改模型或查看完整提示词，需要服务端保存模板、校验变量并组装生成请求，浏览器只接收表单描述与结果。已经交付的完整画布副本无法靠前端实现保密。

## 未来使用流程

作者：整理画布 → 声明变量和固定字段 → 试跑验收 → 发布不可变版本 → 取得分享链接。

使用者：打开链接 → 查看输出说明与所需素材 → 填写文字/上传素材 → 查看预计调用次数或有依据的费用 → 确认生成 → 查看分段进度 → 下载或再做一个。

每次生成创建独立任务，保存模板版本、变量、素材引用、固定参数和后处理配置。模板升级不会修改旧任务；服务端必须准确读取链接指定版本，版本不存在时明确报错，不能静默换成最新版。

## 分阶段实施

### 第一阶段：可重复交接的模板包

先完善小范围文件共享，保留本地执行。

- 增加独立的模板包导出/导入，包含版本、变量定义、固定字段、节点、连线和必要素材；与普通画布项目导出区分。
- 使用素材清单，只纳入作者明确选择的资源；排除生成结果、密钥、历史任务和机器专属路径，导入时检查缺失资源。
- 固定一个示范模板，写清输入要求与预期输出，验证接收者从空白浏览器导入后能创建独立实例。

验收：另一台电脑无需作者的浏览器存储即可读取模板；共享包不含作者视频或凭证；替换变量不会修改原模板。此阶段接收者仍可编辑拿到的代码和画布。

### 第二阶段：跨用户固定模板链接

新增服务端模板与素材存储；首版面向作者邀请的使用者。

- 建立账号、作者发布权限和使用权限，模板默认不公开；分享访问与授权规则单独定义。
- 保存不可变模板版本和共享素材对象，发布前验证素材齐全，链接绑定确定版本。
- 提供独立使用页面，只展示作者开放的变量、输入说明与输出规格；作者保留完整画布编辑入口。
- 为运行创建独立实例；用户之间隔离上传素材与任务，不能通过猜测 ID 读取其他人的内容。

验收：受邀用户用自己的浏览器打开链接即可看到指定版本和素材；新版本发布后旧链接仍指向旧版；无权限用户不能读取模板或他人上传内容。此阶段需明确执行方式，不能把“链接可访问”等同于“无需安装即可生成”。

### 第三阶段：无需本地 Agent 的托管生成

将执行能力移至服务端任务队列和执行器，完成普通使用者的网页闭环。

- 服务端从固定版本构造任务，只接受白名单变量，拒绝改写锁定模型、时长和提示词；凭证由执行器管理。
- 明确费用由谁承担。第一版可选择作者统一提供服务端渠道，但必须有用户用量记录和明确的生成确认；额度、并发、超时和保留期限在实施前确定，不在本规划中预设数值。
- 持久化供应商任务 ID、分段状态和结果。提交状态不明时先查询确认，避免重复创建收费任务；明确失败重试是否新增费用。
- 提供上传、进度、失败恢复、字幕校对、合成下载和“再做一个”。

验收：使用者无需安装工具即可完成生成；刷新后可继续查询；重复点击不会重复计费提交；失败段可单独处理；任务和结果按用户隔离。费用显示无可靠单价时只显示调用次数，以渠道账单为准。

### 后续扩展

在单个固定模板被不同使用者稳定复用后，再考虑相似创作的细粒度权限、更多模板、团队管理、计费及公开目录。多人实时协作和完整视频编辑器不作为首版前置条件。
