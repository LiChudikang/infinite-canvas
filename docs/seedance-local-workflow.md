# Seedance 完整视频工作流

在画布中添加视频配置节点，按从左到右排列；连接参考图片与文本节点。为各段选择 Seedance 模型、时长、比例与清晰度，填写提示词。展开画布右上角“完整视频工作流”，填写可选字幕（每行对应一段）及片尾 Logo，点击“生成完整视频”。每个配置节点只生成一段，费用以方舟账单为准。

工作流支持 16:9 与 9:16，成片分别输出为 1920×1080 或 1080×1920、25 fps。镜头顺序在提交时锁定；同一任务后续不读取修改后的画布。原片的声音会保留，没有音轨的段落补静音；可选字幕和片尾 Logo 由本地 FFmpeg 合成。暂不提供独立音乐上传或完整时间线剪辑器。

## 本地 Agent 配置

需要可执行的 FFmpeg，包含 libx264、AAC、subtitles/libass。中文字幕需要系统中文字体，或通过 WORKFLOW_FONT_FILE 指定字体文件。

```sh
export ARK_API_KEY_FILE="/absolute/path/to/private.env"
export FFMPEG_PATH="/absolute/path/to/ffmpeg"
export WORKFLOW_FONT_FILE="/absolute/path/to/chinese-font.ttf"
cd canvas-agent
npm run dev
```

私有环境文件包含 `ARK_API_KEY=...`，由本地进程读取；也支持直接设置 ARK_API_KEY 环境变量。不要将私有文件提交到 Git。Seedance 请求固定发送至火山方舟北京 API，不接收网页提供的任意 API 根地址或密钥。运行文件位于 `~/.infinite-canvas/video-workflows/<runId>/`，只通过 Agent 现有连接 Token 访问视频。

## 恢复与复用

### Seedance 原生旁白与逐句字幕

视频配置开启声音，在提示词中明确旁白内容。勾选“识别原声逐句字幕”后，Agent 使用本机 faster-whisper 与人声检测生成草稿，暂停在“等待字幕校对”；播放原片核对文字和时间后确认烧录。不能用预期脚本补写模型实际漏念的内容。字幕校对不等于音色、人物一致性或业务内容验收。

本机环境需要安装 `faster-whisper`，设置 `WORKFLOW_PYTHON` 为该环境的 Python，`WORKFLOW_WHISPER_MODEL` 为已下载的 CTranslate2 Whisper 模型目录。本地识别不上传音频，不自动下载模型。两个配置缺失时会在付费请求前拒绝开启自动字幕的运行。识别脚本包含在 `canvas-agent/scripts/transcribe_workflow.py`。

识别草稿和校对稿分别保存为 `subtitles-draft.json` 与 `subtitles-approved.json`；原运行快照不变。字幕时间以各段为零点，必须在片段时长内、顺序排列且不重叠。成片后的“重新校对字幕”生成新的 `final-N.mp4`，旧成片保留，不再次调用 Seedance。

- 查询每 20 秒一次。API 请求沿用已跑通脚本的 120 秒超时，下载沿用 300 秒超时；查询或下载失败后暂停，用户点击“继续查询 / 合成”即可恢复。
- 刷新网页会恢复状态和已完成的视频；Agent 重启后点击“继续查询 / 合成”，按本地快照继续。
- 请求前保存“提交中”标记，收到任务 ID 后立即落盘。如果提交结果不明，不自动重发；在方舟控制台找到对应任务后补充 ID。
- 已明确失败的镜头可单独重新生成（产生一次新调用）；成功镜头复用。
- “接回已经生成的方舟任务”允许按镜头顺序输入已有任务 ID，只查询、下载和合成，不创建付费任务。
- “再做一个”建立新的运行，旧的画布视频与磁盘快照保留。模板发布、实例化和本地运行均独立保存快照。
